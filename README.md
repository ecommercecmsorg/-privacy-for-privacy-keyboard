## 🔐 Privacy Policy – Privacy Keyboard

**Effective date:** 11 May 2026

Privacy Keyboard is a lightweight keyboard app that allows users to type text and optionally improve it using AI-powered grammar, spelling, and punctuation correction.

This document explains how the app handles user data.

---

## 📌 Overview

Privacy Keyboard is designed with privacy in mind:

* No user accounts
* No advertising
* No tracking or profiling
* No permanent storage of typed text by default

---

## ⌨️ User-Generated Text

* The app processes text that users type using the keyboard.
* This text is used only to provide keyboard functionality and optional AI correction.
* Typed text is not permanently stored on servers.

---

## 🤖 AI Text Correction (Optional Feature)

* Users may optionally send selected text to an AI service (e.g., Google Gemini API) for grammar and spelling correction.
* This happens only when the user explicitly triggers the feature.
* No automatic background sending of data occurs.

---

## 🔄 Data Sharing

We do not sell or share personal data.

User text is only shared when:

* The AI correction feature is used
* Text is sent to a third-party AI service for processing

No other data is shared with third parties.

---

## 💾 Data Storage

* Typed text is processed temporarily in memory.
* The app does not store keystrokes or user text permanently on servers.
* No cloud history or user profiles are created.

---

## 🔒 Security

* All external API communication uses encrypted connections (HTTPS).
* No login or authentication system is required.

---

## 👤 User Control

* AI correction is fully optional
* Users decide when (or if) their text is sent to external services

---

## 👶 Children’s Privacy

This app does not target children under the age of 13 (or applicable local minimum age). No personal data is knowingly collected from children.
